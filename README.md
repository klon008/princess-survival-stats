# Princess Survival — статистика плейтестов

Интерактивный дашборд забегов из технических отчётов матча: винрейт по
героям, аренам и версиям сборки, доли урона по способностям, частота пиков
талантов, карты Таро, длительность и убийства.

Страница: **https://klon008.github.io/princess-survival-stats/**

Данные приходят из Google Формы, которую тестеры заполняют в конце забега;
дашборд пересобирается скриптом по мере новых плейтестов. Здесь лежит только
итоговая HTML-страница, код игры и сырые ответы не публикуются.

Графики — [Chart.js](https://www.chartjs.org/) (подгружается с CDN).
